Manage an Etsy shop through Open API v3

Usage: etsy-cli [OPTIONS] <COMMAND>

Commands:
  status         Check whether Etsy is connected
  authorize-url  Return an Etsy OAuth authorization URL
  exchange-code  Exchange an Etsy OAuth authorization code
  disconnect     Disconnect Etsy and remove stored credentials
  me             Return the authenticated Etsy user
  shop           Return a shop by numeric shop ID
  listings       List a shop's listings in the requested state
  listing        Return one listing
  inventory      Return inventory for one listing
  receipts       List receipts/orders for a shop
  request        Make an advanced Etsy Open API v3 request
  help           Print this message or the help of the given subcommand(s)

Options:
      --timeout-secs <TIMEOUT_SECS>  HTTP timeout in seconds [default: 30]
  -h, --help                         Print help
