Jarvis Rescue Daemon -- lightweight recovery agent.

Monitors Jarvis components and restarts them on failure. Exposes a WebSocket service for health checks and diagnostics.

Usage: hatch-rescue [COMMAND]

Commands:
  replace-current-vm      Replace the current VM for a rescue-owned Codex session
  codex-inference-bridge  Run one token-gated Codex HTTP/1 bridge to the inference-proxy UDS
  help                    Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help (see a summary with '-h')
