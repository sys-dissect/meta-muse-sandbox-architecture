Notion MCP helper for Jarvis.

Usage: notion-cli [OPTIONS] <COMMAND>

Commands:
  status         Check OAuth state and, when connected, verify MCP connectivity
  authorize-url  Generate an OAuth authorization URL for Notion
  exchange-code  Exchange an OAuth authorization code for tokens
  refresh        Refresh the stored Notion access token
  disconnect     Delete stored Notion OAuth state locally
  list-tools     List the currently exposed remote MCP tools
  call-tool      Call a Notion MCP tool with a JSON arguments object

Options:
      --endpoint <ENDPOINT>          MCP endpoint URL [default: https://mcp.notion.com/mcp]
      --timeout-secs <TIMEOUT_SECS>  HTTP timeout in seconds [default: 120]
  -h, --help                         Print help
